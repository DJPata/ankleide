# Ankleide

Kleiderschrank fotografieren, Anlass wählen, Outfit vorgeschlagen bekommen und sich darin sehen (Google Gemini).

**App öffnen:** https://djpata.github.io/ankleide/

- In Safari öffnen → ⚙︎ → Gemini-Schlüssel eintragen (bleibt nur auf dem Gerät) → Teilen → „Zum Home-Bildschirm“.
- Fotos und Schrank werden nur im Browser des Geräts gespeichert.
- `computer-version/` enthält die Variante mit kleinem Node-Server, bei der der Schlüssel auf dem Computer bleibt.
